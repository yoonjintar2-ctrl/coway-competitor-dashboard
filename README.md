# 코웨이 경쟁사 분석 플랫폼 (내부용 · 읽기 전용)

PC 로컬 대시보드(아덱스·AdCreative·YouTube·네이버 수집)에서 **배포 시점에 출력된 화면 자료**를 그대로 묶은 정적 사이트입니다.
원천 백데이터·DB·수집 기능·자격 증명은 포함하지 않습니다.

- 화면: `index.html` (캠페인 타임라인 · 캠페인 분석)
- 자료: `data/` — 캠페인 목록(`campaigns-*.json`), 캠페인 상세(`campaign/<id>.json`), 보정값·인덱스
- 이미지: `assets/` — 소재 대표 이미지·스토리보드·인쇄 원본(용량 줄인 사본)
- `static.js` 가 화면의 `/api/*` 요청을 `data/*.json` 으로 대신합니다. 수정·수집은 PC 로컬 버전에서만 됩니다.
